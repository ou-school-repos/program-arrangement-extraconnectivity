\begin{abstract}
The vertex isoperimetric problem on the arrangement graph $A(n,k)$ seeks
$R$-element subsets minimizing the cardinality $|\extbd(S)|$ of the external
vertex boundary.  The canonical Star is an obstruction family whose comparison
with the Hamming ball is governed by $m=n-k$ and its branch count $j$, rather
than by a one-way alphabet-size transition.  We exhibit an exact discrete
crossover at $A(10,5)$ and
$R = 26$: the canonical star graph has boundary $|\extbd(S_{\mathrm{star}})| =
\StarBoundary{}$, while a binary hypercube slice embedded in the same graph
attains $|\extbd(\mathcal{C})| = \SliceBoundary{}$, strictly outperforming the
star.  A vertex-by-vertex boundary trace under lexicographic insertion couples
this crossover to a mechanism: the star confines its internal adjacencies to
isolated coordinate fibers, delaying loop closure, whereas the slice spreads
variation across every coordinate.  Encoding the exact search as a Boolean
constraint program over the $|V| = 30{,}240$ vertices of $A(10,5)$, we further
certify $|\extbd(S)| \ge \CertFloor{}$ for every volume-$26$ subset, so the
true optimum is bracketed as
$\CertFloor{} \le |\extbd(S)| \le \SliceBoundary{}$.  This is a finite
computational bracket, not a universal optimality theorem; the Star loses to
the Hamming-ball value for some small branch counts and can beat it after the
explicit $(m,j)$ shoreline is crossed.
\end{abstract}
